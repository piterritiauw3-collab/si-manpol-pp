Kebijakan Privasi

SI-MANPOL Satpol PP (https://si-manpol-pp.vercel.app) adalah aplikasi internal Satuan Polisi Pamong Praja untuk mengelola kegiatan, SPT, laporan, arsip, dan penyusunan bukti dukung SKP. Terakhir diperbarui: 18 November 2026.

Data yang kami kelola

Data akun (nama, email), data personel, kegiatan, SPT, laporan, foto dokumentasi, dan data SKP milik pengguna. Data disimpan di layanan basis data Supabase dan hanya dapat diakses oleh pengguna yang sudah disetujui admin.

Penggunaan Google Drive

Jika pengguna memilih "Hubungkan Google Drive", aplikasi meminta izin https://www.googleapis.com/auth/drive.file. Izin ini hanya mengizinkan aplikasi membuat dan mengelola folder serta berkas yang dibuat oleh aplikasi itu sendiri, di Google Drive milik pengguna. Aplikasi tidak dapat melihat, membaca, atau mengubah berkas lain di Drive pengguna.

Token akses Google hanya disimpan sementara di peramban pengguna dan tidak disimpan di server kami. Pengguna dapat memutus koneksi kapan saja melalui tombol "Putuskan" di aplikasi atau melalui pengaturan akun Google.

Penggunaan informasi yang diterima dari Google API mematuhi Kebijakan Data Pengguna Layanan API Google, termasuk persyaratan Penggunaan Terbatas.

Berbagi data

Kami tidak menjual atau membagikan data pengguna kepada pihak ketiga, kecuali penyedia infrastruktur (Supabase, Vercel, Google Drive atas pilihan pengguna).
